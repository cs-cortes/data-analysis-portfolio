## Projects

### 1. Cyclistic Bike-Share Analysis

**Tools:** Python, Pandas, Matplotlib, Jupyter Notebook

Analysis of bike-share trip data to identify differences in usage patterns between **members and casual riders**.

The project covers:

* Data cleaning and preparation
* Combining multiple monthly datasets
* Data validation
* Datetime manipulation
* Ride-duration analysis
* Usage patterns by day and hour
* Bike-type analysis
* Station analysis
* Data visualization
* Business-oriented insights

**Project:** [`projects/cyclistic-bike-share-analysis`](./projects/cyclistic-bike-share-analysis)

### 2. Online Shop Data Analysis

**Tools:** Python, Pandas, SQL, PostgreSQL, Jupyter Notebook

Analysis of an e-commerce dataset containing customers, orders, products, suppliers, payments, shipments, and reviews.

The project focuses on understanding the structure and quality of relational data before performing analysis.

Key areas include:

* Data profiling
* Primary key validation
* Foreign key validation
* Missing-value analysis
* Duplicate detection
* Outlier identification
* Relational data validation
* Exploratory analysis
* SQL-based analysis

**Project:** [`projects/online-shop-analysis`](./projects/online-shop)
